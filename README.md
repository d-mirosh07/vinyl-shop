# **Vinyl Shop**

## **Опис**

Vinyl Shop - інтернет-магазин для любителів та поціновувачів музики на вінілі.

Користувач може переглядати каталог платівок, шукати їх за назвою, фільтрувати за виконавцем та жанром.
На сторінці платівки видно ціну, наявність, список пісень і відгуки з оцінками інших покупців.
Є сторінки виконавців з усіма їхніми платівками.

Користувач може зареєструватися та увійти.
Зареєстрований користувач може змінити свої дані в профілі, додавати платівки в кошик і натискати купити, після чого створюється замовлення (без оплати та додаткових даних).
Також він бачить історію замовлень і може залишати відгуки з оцінками.

Адміністратор керує каталогом платівок: додає, змінює та видаляє платівки, додає виконавців і жанри.
Також є сторінка «Про нас»(вона статична тому окремого ендпоінта для неї нема) з контактами, інформацією про доставку та повернення.

## API
Усі дані передаються у форматі JSON

## Платівки

### GET /albums - 200
Список платівок з пошуком, фільтрами 

**Параметри (необов'язкові):** `search`, `artist_id`, `genre_id`
```json
[
  { "id": 1, "title": "Thriller", "artist": "Michael Jackson", "genre": "Pop", "price": 899, "in_stock": true }
]
```
### GET /albums/{id} - 200
Сторінка однієї платівки зі списком пісень.
```json
{
  "id": 1,
  "title": "Thriller",
  "artist": "Michael Jackson",
  "genre": "Pop",
  "price": 899,
  "in_stock": true,
  "tracks": [
    { "number": 1, "title": "Wanna Be Startin' Somethin'", "duration": "6:03" }
  ]
}
```
### POST /albums - 201
Адмін додає платівку разом зі списком пісень.

**Тіло запиту:**
```json
{
  "title": "Thriller",
  "artist_id": 2,
  "genre_id": 1,
  "price": 899,
  "in_stock": true,
  "tracks": [
    { "number": 1, "title": "Wanna Be Startin' Somethin'", "duration": "6:03" }
  ]
}
```
**Відповідь:**
```json
{ "id": 1, "title": "Thriller", "price": 899, "in_stock": true }
```
### PATCH /albums/{id} - 200
Адмін змінює ціну чи наявність платівки.

**Тіло запиту** (необов'язкові поля: price, in_stock):
```json
{ "price": 799, "in_stock": false }
```
**Відповідь:**
```json
{ "id": 1, "title": "Thriller", "price": 799, "in_stock": false }
```
### DELETE /albums/{id} - 204
Адмін видаляє платівку . Відповіді немає.

## Виконавці

### GET /artists - 200
Список виконавців.
```json
[
  { "id": 2, "name": "Michael Jackson" }
]
```
### GET /artists/{id} - 200
Сторінка виконавця з усіма його платівками.
```json
{
  "id": 2,
  "name": "Michael Jackson",
  "albums": [
    { "id": 1, "title": "Thriller", "price": 899, "in_stock": true }
  ]
}
```
### POST /artists - 201
Адмін додає виконавця.

**Тіло запиту:**
```json
{ "name": "Michael Jackson" }
```
**Відповідь:**
```json
{ "id": 2, "name": "Michael Jackson" }
```

## Відгуки

### GET /albums/{id}/reviews - 200
Відгуки про платівку.
```json
[
  { "id": 12, "user": "Daria", "rating": 5, "text": "Чудовий звук" }
]
```
### POST /albums/{id}/reviews - 201
Зареєстрований користувач додає відгук і оцінку.

**Тіло запиту:**
```json
{ "user_id": 3, "rating": 5, "text": "Чудовий звук" }
```
**Відповідь:**
```json
{ "id": 12, "rating": 5, "text": "Чудовий звук" }
```

## Кошик

### GET /users/{id}/cart - 200
Вміст кошика користувача.
```json
[
  { "album_id": 1, "title": "Thriller", "quantity": 2, "price": 899 }
]
```
### POST /users/{id}/cart - 201
Додає платівку в кошик. Якщо платівки немає в наявності, повертається 400 

**Тіло запиту:**
```json
{ "album_id": 1, "quantity": 2 }
```
**Відповідь:**
```json
{ "album_id": 1, "quantity": 2 }
```
## Замовлення

### POST /orders - 201
Кнопка купити створює замовлення з усього, що лежить у кошику, і очищає кошик.
Якщо кошик порожній, повертається 400

**Тіло запиту:**
```json
{ "user_id": 3 }
```
**Відповідь:**
```json
{ "id": 21, "total_price": 1798, "created_at": "2026-10-11" }
```
### GET /users/{id}/orders - 200
Історія замовлень користувача з платівками.
```json
[
  {
    "id": 21,
    "created_at": "2026-10-11",
    "total_price": 1798,
    "items": [
      { "title": "Thriller", "quantity": 2, "price": 899 }
    ]
  }
]
```
