# **Vinyl Shop**

## **Опис**

Vinyl Shop - інтернет-магазин для любителів та поціновувачів музики на вінілі.

Користувач може переглядати каталог платівок , шукати їх за назвою та фільтрувати за виконавцем і жанром.
На сторінці платівки видно ціну, наявність і відгуки з оцінками інших покупців.
Є сторінки виконавців з усіма їхніми платівками.


Користувач може зареєструватися та увійти.
Зареєстрований користувач може змінити свої дані в профілі, додавати платівки в кошик і натискати купити, після чого створюється замовлення (без оплати та додаткових даних).
Також він бачить історію замовлень і може залишати відгуки з оцінками.

Адміністратор керує каталогом платівок: додає, змінює та видаляє платівки, додає виконавців і жанри.
Також є сторінка «Про нас»(вона статична тому окремого ендпоінта для неї нема) з контактами, інформацією про доставку та повернення.

## Як запустити проєкт 
1. Створити й увімкнути віртуальне середовище:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Встановити залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Виконати міграції:
   ```bash
   python manage.py migrate
   ```
4. Запустити сервер:
   ```bash
   python manage.py runserver
   ```

Бекенд працює на `http://127.0.0.1:8000/`, усі адреси починаються з `/api/`.
Фронтенд окремий репозиторій `vinyl-shop-frontend` працює на `http://localhost:63342`, цей порт дозволений у `CORS_ALLOWED_ORIGINS`.

## Postman

Колекція лежить у `postman/vinyl-shop.postman_collection.json`. Базова адреса винесена у змінну `base_url`.
Запити слід виконувати по порядку: спершу створити виконавця й жанр, потім платівку.

## API
Усі дані передаються у форматі JSON

## Платівки

### GET /albums - 200
Список платівок з пошуком і фільтрами.
```json
[
  { "id": 1, "title": "Thriller", "price": "899.00", "in_stock": true, "artist": 1, "genre": 1 }
]
```
### GET /albums/{id} - 200
Одна платівка. Якщо її немає, повертається 404.
```json
{ "id": 1, "title": "Thriller", "price": "899.00", "in_stock": true, "artist": 1, "genre": 1 }
```
### POST /albums - 201
Адмін додає платівку.

**Тіло запиту:**
```json
{ "title": "Thriller", "price": "899.00", "in_stock": true, "artist": 1, "genre": 1 }
```
**Відповідь:**
```json
{ "id": 1, "title": "Thriller", "price": "899.00", "in_stock": true, "artist": 1, "genre": 1 }
```
### PATCH /albums/{id} - 200
Адмін змінює ціну чи наявність платівки.

**Тіло запиту** (необов'язкові поля: price, in_stock):
```json
{ "price": "799.00", "in_stock": false }
```
**Відповідь:**
```json
{ "id": 1, "title": "Thriller", "price": "799.00", "in_stock": false, "artist": 1, "genre": 1 }
```
### DELETE /albums/{id} - 204
Адмін видаляє платівку. Відповіді немає.

```json
{ "id": 1, "name": "Michael Jackson" }
```
### POST /artists - 201
Адмін додає виконавця.

**Тіло запиту:**
```json
{ "name": "Michael Jackson" }
```
**Відповідь:**
```json
{ "id": 1, "name": "Michael Jackson" }
```
### PATCH /artists/{id} - 200
Адмін змінює виконавця.

**Тіло запиту** (необов'язкове поле: name):
```json
{ "name": "Michael J. Jackson" }
```

## Кошик

### GET /users/{id}/cart - 200
Вміст кошика користувача.
```json
[
  { "album_id": 1, "title": "Thriller", "quantity": 2, "price": 899 }
]
```
### POST /users/{id}/cart - 201
Додає платівку в кошик. Якщо платівки немає в наявності, повертається 400

**Тіло запиту:**
```json
{ "album_id": 1, "quantity": 2 }
```
**Відповідь:**
```json
{ "album_id": 1, "quantity": 2 }
```
## Замовлення

### POST /orders - 201
Кнопка купити створює замовлення з усього, що лежить у кошику, і очищає кошик.
Якщо кошик порожній, повертається 400

**Тіло запиту:**
```json
{ "user_id": 3 }
```
**Відповідь:**
```json
{ "id": 21, "total_price": 1798, "created_at": "2026-10-11" }
```
### GET /users/{id}/orders - 200
Історія замовлень користувача з платівками.
```json
[
  {
    "id": 21,
    "created_at": "2026-10-11",
    "total_price": 1798,
    "items": [
      { "title": "Thriller", "quantity": 2, "price": 899 }
    ]
  }
]
```
